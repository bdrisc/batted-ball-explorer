How to Read This

Start with the heatmap. Pick an exit speed, then compare the launch angles and directions. Stronger green means a higher predicted value for the metric you choose.

Use 3D to see the whole picture. Each dot represents a speed and angle combination. Distance from home plate represents exit speed. This is a map of contact quality, not a ball’s flight path.

Bring in a hitter. Blue dots show his actual contact. Look for where those dots sit. Left handed contact is flipped so the pull side is always on the left in the starting view.

Hit probability estimates the chance of a hit. Modeled wOBAcon gives extra credit to extra base hits using fixed weights. Blank areas have too little nearby training data to display.
